# Blugold Group Docs

Our documentation page is built using [Docusaurus](https://docusaurus.io/) for ease of use.

## Local Development

This site runs using [Node.js](https://nodejs.org/en/download)

### Prerequisites:
- npm
- Node.js
- Docusaurus (npm package)

### Installing Node.js and npm

Fedora: `sudo dnf install nodejs`

### Installing Docusaurus

Fedora: `npm install docusaurus`

Once you have Node.js, npm, and Docusaurus installed, navigate to the project directory (the root of the repository) and run `npm start`

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.
By default, the server is hosted at `http://localhost:3000`.
